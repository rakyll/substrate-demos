# Agent Substrate Demos

A collection of demos showcasing Agent Substrate.

## Demos

| Demo | Description |
| --- | --- |
| [Environment](env/) | Sandbox lifecycle walkthrough using the `ate-env` CLI. |
| [Antigravity](antigravity/) | Route Antigravity CLI (`agy`) tools into a sandbox via MCP. |
| [Claude](claude/) | Route Claude Code tools into a sandbox via MCP. |
| [Cursor](cursor/) | Route Cursor Agent tools into a sandbox via MCP. |
| [VS Code](vscode/) | Connect desktop VS Code into an on-demand sandbox via Remote Tunnels. |
| [GitHub Actions](github-actions/) | Run automated CI checks and untrusted PR workloads inside sandboxes. |
